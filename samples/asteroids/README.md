# Asteroids

An Asteroids clone built up one step at a time, in the same incremental style as the [Breakout](../breakout/) series. Each sample builds on the one before it.

## Roadmap

| # | Sample | Topic |
|---|--------|-------|
| 1 | [Asteroids Ship](asteroids_ship/README.md) | Rotation, thrust, inertia, and screen wrap |
| 2 | [Asteroids Bullets](asteroids_bullets/README.md) ([tutorial](asteroids_bullets/TUTORIAL.md)) | Spawning projectiles along the ship's heading, cooldown, lifetime, bullet cap, and mesh cleanup |
| 3 | [Asteroids Rocks](asteroids_rocks/README.md) ([tutorial](asteroids_rocks/TUTORIAL.md)) | Drifting rocks, circle-vs-circle collision, splitting large rocks into smaller ones, score |
| 4 | [Asteroids Lives](asteroids_lives/README.md) ([tutorial](asteroids_lives/TUTORIAL.md)) | Ship-vs-rock collision, respawn with temporary invulnerability, game over, HUD |
| 5 | [Asteroids Waves](asteroids_waves/README.md) ([tutorial](asteroids_waves/TUTORIAL.md)) | Wave progression, safe spawn distance from the ship, difficulty scaling, procedurally shaped rocks |
| 6 | [Asteroids UFO](asteroids_ufo/README.md) ([tutorial](asteroids_ufo/TUTORIAL.md)) | An enemy saucer that aims and fires back; simple AI and targeting math |
| 7 | [Asteroids Polish](asteroids_polish/README.md) ([tutorial](asteroids_polish/TUTORIAL.md)) | Start screen and pause, particle explosions, synthesized thrust/fire/explosion sounds, hyperspace |
| 8 | [Asteroids Next Steps](asteroids_next_steps/README.md) ([tutorial](asteroids_next_steps/TUTORIAL.md)) | Lit 3D rocks, 3D ships (choose one) and saucers under the same gameplay, optional chase-camera mode |

The plan may shift as each step teaches something unexpected.
