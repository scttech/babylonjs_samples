# Rolling Rampage assets

The pictures and fonts the Rolling Rampage samples share. There are no 3D models in this series: the game is built from boxes and spheres, and from code.

| Folder | What's in it | Used for |
|---|---|---|
| `images/` | The logo: `rolling_rampage_logo.png` (the full-size original, on white) and `rolling_rampage_logo_small.webp` (800 pixels wide, with the white background made transparent) | The READMEs, the splash and the title screen |
| `fonts/` | Russo One, Barlow Condensed (semi-bold and bold) and Saira Stencil One, with their licenses | The text in the game |

## The look

The colors and fonts come from the logo: riveted gunmetal, chrome lettering, hazard-stripe yellow, safety orange and one cool blue.

| Role | Color |
|---|---|
| Ink (the outline round everything) | `#0b0909` |
| Gunmetal | `#211e21`, `#30384a`, `#4b5367` |
| Chrome | `#757d8e`, `#a2adc0`, `#d9dbdc` |
| Hazard yellow (the main accent) | `#f6bf0e` |
| Safety orange (danger) | `#ef5e07` |
| Rust (pressed and dim) | `#b25b0e`, `#6b2e0c` |
| Sky blue (the one cool color, for good things) | `#248de3` |
| Behind the course | `#161b26` |

| Font | For |
|---|---|
| **Russo One** | Big words and numbers: a wide, heavy font, close to the weight of "ROLLING" in the logo |
| **Barlow Condensed** | Everything small, and the one to fall back on: a road-sign font that is very legible at small sizes and narrow enough for a phone |
| **Saira Stencil One** | A few labels, and only big: stencil letters have gaps that hurt readability when small |

## Changes made to the files

The small logo was made from the original: the white background was removed (white that touches the edge became transparent, and the pixels along the edge were faded so there is no white fringe), it was shrunk to 800 pixels wide, and it was saved as WebP, which keeps transparency at about a tenth of the size of a PNG.
