# Model Lab assets

| Folder | What | Where it is from | Licence |
|--------|------|------------------|---------|
| `images/` | The Model Lab logo, in two sizes (the full-size original is in `source_assets/`) | Made for this project | The same as the rest of the repo |
| `characters/` | `fire.glb`, `air.glb` and `heavy.glb`: three rigged characters, each with the same 24-bone skeleton and its own set of animation clips | Copies of `tower_defense/assets/benders/fire.glb`, `.../benders/air.glb` and `.../enemies/heavy.glb`, made with [Meshy](https://www.meshy.ai) and given to this project by its owner | Creative Commons: use, sharing and modification allowed (credit to Meshy) |

The characters are the ones in the Tower Defense series, which is a non-commercial fan project in the world of *Avatar: The Last Airbender* (see its [README](../../tower_defense/README.md)). They are copied here so that this series does not depend on that one.
